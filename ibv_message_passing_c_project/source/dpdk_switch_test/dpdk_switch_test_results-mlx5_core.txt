0. Introduction
===============

This is using the mlx5_core module when the IOMMU is enabled, on a ConnectX-4 100G device.

A QSFP DAC cable connects the ConnectX-4 100G port to an Alveo U200 with the
https://github.com/Chester-Gillon/fpga_sio/tree/main/fpga_tests/U200_100G_ether_duplex design.
xilinx_axi_stream_switch_configure was used to loopback the U200 CMAC 100G port rx -> tx AXI4 streams,
so that the packets transmitted by the ConnectX-4 get received unmodified.
